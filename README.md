# 坦克大战 (Tank Battle)

一个用原生 HTML5 Canvas + JavaScript 写的坦克大战小游戏，**零依赖、单文件**，双击 `index.html` 就能玩。

## 玩法

- 消灭全部 6 辆敌方坦克即获胜；3 条命用完则游戏结束
- 敌方坦克同屏最多 3 辆，分批从地图上方投放
- 砖墙（棕色）可以被子弹打碎，钢墙（灰色）打不穿，可以用来当掩体

## 操作

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 移动 |
| `空格` | 开火 |
| `R` | 游戏结束后重新开始 |

## 运行

直接用浏览器打开 `index.html` 即可，不需要安装任何东西。

也可以起一个本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 实现要点

- **地图**：15×15 的格子，用字符数组声明，`#` 砖墙 / `@` 钢墙 / `.` 空地
- **移动**：分轴推进 + 通道自动吸附，坦克在窄缝里不会卡住
- **碰撞**：矩形与所在格子的 AABB 检测，子弹分步推进防止高速穿墙
- **敌方 AI**：随机游走，约六成概率朝玩家方向转向，撞墙即换向；随机开火
